# deft-libxumux

An alias of [`libxumux`](https://www.npmjs.com/package/libxumux), the TypeScript implementation of the [xumux](https://github.com/deftai/xumux) multiplexing protocol. It re-exports `libxumux` and all its subpaths (`pipe`, `transports/*`).

```sh
npm install libxumux        # preferred
npm install deft-libxumux   # same thing
```

Documentation and source: https://github.com/deftai/libxumux
